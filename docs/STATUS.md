## 版本與功能（v0.1.0）

**做了**
- 主畫面：2 欄 × 5 列房間格，照門牌自然排序、位置固定；四種狀態都有「圖示＋字＋底色」；上月／下月／回到本月。
- 點格子 → 金額、繳款日 →「收到了」→ 大字確認頁（可拍收據、可改金額與收款日）→「確定收到」。
- 已收的格子再點一次 →「改回沒收到」（第二顆按鈕）。
- 還沒收 → 選原因（晚輩可改選項）或自己寫；格子上顯示原因前三個字。
- 這個月最後一戶收齊時，問一次「要不要傳一份紀錄給家人」。
- 備份：先準備好 `.html` 檔，按鈕一按就叫出 iPhone 的分享畫面；分享成功才記「已傳出」，取消不算。
- 提醒：從沒傳過、第一筆資料滿 7 天，或上次傳出超過 30 天，而且之後有新紀錄 → 格子上方一條（最多兩行）；備份頁可「這週先不要」，不能永久關閉。
- 從備份找回：驗證內容雜湊 → 摘要 → 手機上已有資料時，一定要先存一份目前的 → 輸入「找回」→ 還原 → 重算雜湊確認完全相同。
- 晚輩設定（按住 3 秒；切到背景或 3 分鐘沒動作自動離開）：
  - 資料安全：「如果現在被清掉，會損失多少」、上次傳出、還沒傳出的變更、開啟方式、持久儲存、已用空間；
  - 租客新增、修改、↑↓ 排序、依門牌重排、搬走與搬回；
  - 字級四檔＋「平常／出現提醒時一屏放不放得下」的實測＋太長的格子名稱；
  - 備份收件人稱呼、原因選項；異動紀錄最近 30 筆。
- 不是從主畫面圖示打開：只顯示安裝說明；晚輩可按「預覽」在瀏覽器裡看（紅色橫條警告資料可能被清掉）。
- 空的 App：「紀錄不見了請打電話給家人」＋「從備份找回」＋「第一次使用」。

## 踩過的坑

1. **提示條蓋住按鈕**：只點一下「晚輩設定」時跳出的「要按住 3 秒」提示條，剛好蓋在按鈕上，晚輩馬上再按住時按到的是提示條，怎麼按都進不去。修法：提示條 `pointer-events: none`。是端對端測試的「按住 3 秒」那一條抓到的。
2. **提醒卡把房間格擠出畫面**：剛設定完、還沒傳過備份就立刻出現約 170 點高的提醒卡，「大」字級在 320×626 下最後一格跑到 698。改成：從沒傳過時，第一筆資料滿 7 天才提醒；提醒條最多兩行；晚輩頁分開顯示「平常／出現提醒時」放不放得下。
3. **puppeteer 安裝失敗**：附帶的瀏覽器下載失敗。用 `PUPPETEER_SKIP_DOWNLOAD=1 npm install`，Chrome 131 已在 `~/.cache/puppeteer`。
4. **測試裡的重新載入**：「畫完幾次」的計數在新頁面會歸零，用 `reload()` 輔助函式等第一次畫完，不要用 `nav()`。
