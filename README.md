# 收租紀錄（RentCheck）

給長輩用的收租確認 App（iPhone 主畫面網頁 App）。

- **一屏看完 10 戶**：2 欄 × 5 列的房間格，照門牌排、位置固定；每格只寫門牌與狀態（已收／該收了／還沒到／沒收＋原因）。
- **大字**：四檔字級，在設定裡看著預覽選；放不下時不縮字。
- **按錯可以改回**：確認收款多一頁大字確認；之後點同一格就能「改回沒收到」，沒有會消失的「復原」按鈕。
- **設定**要按住 3 秒才進得去；App 切到背景或 3 分鐘沒動作就自動離開。
- **備份是正本**：紀錄只在手機裡，可能被 iPhone 清掉而且沒有提示。所以有一顆「匯出備份」，叫出 iPhone 的分享畫面，存去哪由使用者決定（「檔案」、iCloud…）。檔案存在 App 以外，App 的資料被清掉時它還在。每份備份都完整（文字＋最近 24 個月的收據照片），檔案本身點開就是一張看得懂的表。

免帳號、無伺服器、離線可用。原生 JS（ES modules）＋ IndexedDB ＋ Service Worker，不用框架、不用打包。
